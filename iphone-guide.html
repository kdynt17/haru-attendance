아이폰에서도 하루 출석부

단축어 앱이나 앱스토어 설치 없이, Safari에서 홈 화면에 추가해 사용합니다.

1. 홈 화면에 설치

  1. 아이폰 Safari에서 하루 출석부 주소를 엽니다. 로그인 없이 사용할 수 있습니다.
  2. 공유 → 홈 화면에 추가를 선택합니다. ‘웹 앱으로 열기’가 보이면 켜고 추가를 누릅니다.
  3. 홈 화면의 하루 출석부 아이콘으로 다시 엽니다. 최초에는 인터넷에 연결해 오프라인 준비 완료 표시를 확인하세요.
  4. 학급 설정에 학생 명단을 저장하고 사용합니다. 기존 기록이 있다면 먼저 전체 백업을 가져오세요.

공유 메뉴에서 항목이 안 보이면 아래로 스크롤하거나 ‘동작 편집’을 확인하세요. 카카오톡 안의 브라우저 대신 Safari에서 여세요.

2. 기록과 저장

오늘 출결: 학생의 지각·결석·조퇴·결과 버튼 → 시간·사유 선택 → 기록 저장. 잘못 저장했다면 마지막 출결 실행 취소를 누릅니다. 실행 취소는 앱을 연 동안 마지막 변경 한 번입니다.

누가 기록: 날짜 → 학생 → 내용 입력 → 저장. 출결과 별도로 보관합니다.

저장 위치: 이 아이폰의 웹앱 저장소(IndexedDB)입니다. 저장 버튼으로 기록하면 앱을 닫았다 열어도 유지됩니다. 인터넷에 자동 업로드하거나 PC·갤럭시·다른 아이폰과 동기화하지 않습니다.

홈 화면 앱과 Safari 창에서 기록이 공유된다고 가정하지 말고, 항상 같은 홈 화면 아이콘으로 사용하세요. 주소·브라우저가 달라지면 별도 저장소입니다.

오프라인 준비 완료 후에는 인터넷 없이 출결·누가기록을 사용할 수 있습니다. 최초 로그인·설치, 업데이트, PC의 나이스 입력에는 인터넷이 필요합니다.

3. 전체 백업은 ‘파일’ 앱에

  1. PC로 보내기 → 전체 백업을 펼칩니다.
  2. 백업 공유 · 파일에 저장 → 파일에 저장을 선택합니다.
  3. iCloud Drive 또는 나의 iPhone에 저장합니다. 기기 교체에 대비하려면 iCloud Drive에 보관하세요.
  4. 파일 앱에서 전체백업_날짜.neisatt 파일이 실제로 있는지 확인합니다.

파일 다운로드를 선택했다면 Safari 다운로드 목록 또는 파일 앱의 다운로드 폴더를 확인하세요. 공유 화면을 취소하면 파일은 저장되지 않습니다.

전체 백업에는 학생 명단·출결·누가기록·설정이 포함됩니다. 꾸미기 표지는 제외됩니다. 백업 파일은 암호화되지 않으므로 본인 저장소에 보관하세요.

4. 기기를 바꾸거나 기존 APK 기록 가져오기

  1. 원래 기기에서 전체 백업 저장으로 파일을 만듭니다.
  2. 아이폰으로 파일을 옮긴 후, 설치한 홈 화면 앱을 엽니다.
  3. PC로 보내기 → 파일 / 클립보드 불러오기에서 백업 파일을 선택합니다.
  4. 명단과 기록 수를 확인한 후 전체 백업으로 교체를 선택합니다. 현재 아이폰에 기록이 있으면 먼저 그 기록도 백업하세요.

상단의 출결 파일 저장은 누가기록을 포함하지 않습니다. 누가기록만 PC로 보낼 때는 별도의 누가 기록 파일 저장을 사용하세요.

업데이트해도 유지되나요?

같은 주소에서 앱 코드만 업데이트하면 기존 기록을 유지합니다. 다만 앱·웹사이트 데이터 삭제, 저장공간 정리, 기기 분실·교체로 기록을 잃을 수 있어 영구 보관을 보장할 수는 없습니다. 매주 한 번, 삭제·기기 변경 전에는 전체 백업을 권합니다.

iCloud Drive에 백업 파일을 저장하는 것은 수동 백업입니다. 앱의 기록이 iCloud로 자동 동기화되는 것은 아닙니다.
