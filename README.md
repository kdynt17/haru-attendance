# 하루 출석부

아이폰·안드로이드 홈 화면에서 사용하는 출결 및 누가기록 웹앱입니다.

- Safari → 공유 → 홈 화면에 추가
- 학생 명단·출결·누가기록은 각 기기의 IndexedDB에 저장됩니다.
- 서버로 기록을 전송하거나 기기 간 자동 동기화하지 않습니다.
- PC로 보내기 → 전체 백업으로 정기적으로 파일을 보관하세요.
- 기존 주소에서 옮길 때 전체 백업 → 새 주소에서 파일 불러오기를 사용하세요.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.
서비스 워커 사용을 위해 HTTPS 주소로 접속합니다.

이 저장소에는 앱 코드와 정적 파일만 포함합니다. 학생 기록·백업·비밀키는 올리지 마세요.
